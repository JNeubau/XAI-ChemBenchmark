# XAI-ChemBenchmark

This repository contains the code and data for the paper, "Comparative analysis of model-agnostic explanation methods in materials science".

## Overview

Machine learning models are accelerating discovery in materials science by accurately predicting molecular properties. However, their "black-box" nature often obscures the reasoning behind their predictions, making them difficult to validate or trust. Explainable Artificial Intelligence (XAI) aims to solve this by making models more transparent. This is crucial in chemistry, where understanding structure-property relationships is essential for designing novel molecules.

Despite this need, there is a lack of systematic XAI benchmarks focused on molecular data. This project takes a foundational step to address this gap by presenting **a comparative analysis of XAI methods on ECFP molecular fingerprints**.
In particular, we empoly LIME, SHAP, SHAP-IQ, MMACE and MEG methods.

Our key findings reveal **significant discrepancies** in the feature importance rankings generated by different XAI methods. This demonstrates that the choice of explanation technique can introduce bias and fundamentally alter the scientific insights derived from the model, impacting the material discovery process.

This repository provides the tools to reproduce our findings and data used in the study.
